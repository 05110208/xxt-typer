# xxt_typer

面向「网页禁止粘贴」场景的**键盘逐字输入工具**：把文本拆成一个个真实按键送进当前窗口，
绕过网页对 `paste` / `Ctrl+V` 的拦截。典型用途是超星学习通等作业页，也适用于任何被禁用了
粘贴的输入框；代码模式下还能当 IDE 的辅助输入用。

工具**完全不使用剪贴板**，发出的是普通键盘事件。

## 特性

- **两种模式，自动套用合适的参数**
  - **文字模式**：Unicode 直发字符，支持中文和全角标点，不受输入法状态影响
  - **代码模式**：真实键码（虚拟键码 + 扫描码 + Shift），编辑器的回车自动缩进、括号自动补全
    都会被正常触发；配对的收尾括号改为按**右方向键**跳过，避免 `}` 变成 `}}`
- **不会打错窗口**：活动窗口是工具自己时拒绝输入；开始输入前会显示目标窗口标题供你确认
- **随时接管**：`F8` 暂停 / 继续，`F9` 立即停止
- **换行可控**：`Enter` 或 `Shift+Enter`，回车一律带扫描码发送，兼容富文本编辑器
- 纯本地运行，除了 `pynput` 没有第三方依赖

## 快速开始

要求 Windows 10/11 + Python 3.11（conda 或官方安装包都行）。

```bat
install.bat     :: 创建独立 conda 环境 xxt-typer，装依赖并跑一次自检
run.bat         :: 打开图形界面
```

不用 conda 也可以：

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python xxt_typer.py
```

## 使用

1. 打开 `run.bat`，把要输入的内容粘到上面的大文本框（这个框没有限制，随便粘）
2. 在「使用模式」里选 `文字模式` 或 `代码模式`，点 **开始输入 (F8)**
3. 用鼠标点一下目标输入框；状态栏会显示 `2.0 秒后开始输入到「窗口标题」…（F9 取消）`
4. 标题正确就等它逐字打完；不对就按 `F9`

### 模式预设

| 设置 | 文字模式 | 代码模式 |
| --- | --- | --- |
| 输入方式 | Unicode 直发 | 真实键码（**需要把输入法切到英文**） |
| 字符间隔 / 换行后等待 | 30 / 200 毫秒 | 15 / 120 毫秒 |
| 跳过编辑器补全的 `) ] }` | 关 | 开 |
| 跳过源文本行首缩进 | 关 | 开 |

切换模式会套用这套推荐值，之后每个选项都能单独微调。

| 选项 | 说明 |
| --- | --- |
| 换行方式 | 普通文本框、代码编辑器用 `Enter`；富文本编辑器想软换行用 `Shift+Enter` |
| 忽略空行 | 默认保留空行，代码和排版场景不建议勾 |
| 引号 `"` `'` 也一起处理 | 仅当编辑器连引号也会自动补全时才需要 |
| 开始前倒计时 | 留出把鼠标点到目标窗口的时间 |

### 命令行

```bat
python xxt_typer.py --file 答案.txt --countdown 5
python xxt_typer.py --file main.cpp --code --countdown 5
```

| 参数 | 说明 |
| --- | --- |
| `--file` / `-f`、`--text` / `-t` | 内容来源；`-f -` 表示从标准输入读 |
| `--code` | 代码模式预设（真实键码 + 跳过补全括号 + 跳过行首缩进） |
| `--mode` | `unicode`（默认）/ `keys` / `pynput` |
| `--newline` | `enter`（默认）/ `shift+enter` |
| `--delay`、`--line-delay`、`--countdown` | 字符间隔、换行等待（毫秒）、倒计时（秒） |
| `--skip-empty-lines` | 跳过空行 |
| `--no-auto-skip`、`--auto-skip-quotes` | 收尾括号 / 引号的自动跳过开关 |
| `--strip-leading-indent` | 换行后跳过行首缩进 |

## 常见问题

**目标框里一个字都没进去**
确认倒计时结束时鼠标点在目标框内、光标在闪；把「字符间隔」调大到 50~80 毫秒；
或改用代码模式（记得先切英文输入法）。

**换行偶尔不生效**
把「换行后等待」调大到 300~500 毫秒（编辑器要处理自动缩进、预览刷新）；
富文本编辑器里改用 `Shift+Enter`。

**代码里 `}` 变成 `}}`、`))` 重复**
用代码模式，并保持「跳过编辑器补全的括号」勾选。如果你的编辑器**不会**自动补全括号，
把这个选项取消勾选，否则收尾括号会被少打。

**缩进变成双倍**
编辑器回车后会自动缩进，工具再补一次就翻倍了。代码模式默认会跳过源文本的行首空格；
编辑器不自动缩进时取消勾选即可。

**字母变成了拼音**
代码模式用真实键码，中文输入法开着会被截走成拼音。按 `Shift` 切到英文再开始（工具会在
状态栏提醒）。

**`F8` / `F9` 没反应**
个别安全软件会拦全局快捷键，用界面上的按钮即可，功能一样。

**想看到报错信息**
在控制台里跑 `conda run -n xxt-typer python xxt_typer.py`，日志同时写在同目录的
`xxt_typer.log`。

## 实现简述

| 通道 | 实现方式 | 用途 |
| --- | --- | --- |
| Unicode 直发 | `SendInput` + `KEYEVENTF_UNICODE` | 文字模式：不受输入法影响，支持中文与全角标点 |
| 真实键码 | `SendInput` 的虚拟键码 + 扫描码 + Shift（布局经 `VkKeyScanEx` 解析） | 代码模式：编辑器能拿到完整的按键事件 |
| pynput | `pynput.keyboard.Controller` | 兼容个别只认键码的旧编辑器 |

代码模式下非 ASCII 字符（例如中文注释）会自动回退到 Unicode 通道。
`AutoCloseTracker` 维护一个"自己打出去的开括号"栈，源文本里与之配对的收尾括号改为发送
右方向键跳过，从而和编辑器的自动补全对齐。

## 自检

```bat
python selftest.py            :: 纯逻辑 + 界面 + 目标窗口守卫 + 按键事件干跑（不发送任何按键）
python selftest.py --inject   :: 额外跑真实弹窗注入测试（会短暂抢占前台焦点）
```

`--inject` 会先新建自己的窗口并确认抢到焦点，抢不到就跳过，不会把按键送进你正在用的窗口。
